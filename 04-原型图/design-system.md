# 设计系统 · 古树名木养护档案管理系统

## 1. 视觉方向
「医疗青蓝」专业业务系统风格：强调数据可读性、操作效率与状态辨识。不使用巨幅英文口号、装饰光效、
悬浮球、过度渐变或大面积插画。卡片圆角 6–8px，阴影只用于抽屉与弹窗，正文使用系统中文字体，
数字列使用等宽数字特性，接近真实单位内部系统。

## 2. 色彩
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#174A5C` | 顶部栏、主按钮、当前菜单、关键数字 |
| 辅助色 | `#2A7F86` | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 | `#F3F8F8` | 主内容区背景，表格与表单用白色容器 |
| 强调色 | `#316B74` | 链接、信息提示、图表对比系列 |
| 成功色 | `#247A58` | 已完成、已通过、正常 |
| 危险色 | `#A62B32` | 驳回、超时、异常、删除确认（仅小面积） |
| 分割线 | `#DBE7E8` | 表格与卡片边框 |

状态不能只靠颜色表达，必须同时显示中文标签（见 `StatusTag` 组件）。

## 3. 字体阶梯
| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 20/28 | 600 | 详情页档案编号 |
| 卡片标题 | 15/22 | 600 | 卡片头部 |
| 正文 | 14/22 | 400 | 表单、正文 |
| 辅助 | 13/20 | 400 | 表格内容、说明 |
| 小字 | 12/18 | 400 | 时间、备注、单位 |

## 4. 间距与栅格
- 内容区外边距 24px；卡片内边距 16–18px；卡片间距 16px
- 筛选区行间距 12px；表格行高 44px；按钮高度 32px（小号 28px）
- 桌面端 220px 侧边栏 + 56px 顶栏 + 自适应内容区；侧边栏折叠后 64px

## 5. 组件规范
- 按钮：主按钮实心主色；次按钮白底描边；危险操作红色描边 + 二次确认
- 输入：高度 32px，圆角 6px，标签宽度 100–120px，单列输入 360–520px
- 下拉：搜索区下拉宽度 180–240px
- 表格：表头浅青底 `#EEF5F5`，表头不固定宽度按内容自适应，编号/状态/日期/操作列单行
- 状态标签：浅底 + 同色描边 + 中文文字
- 抽屉：用于审批与流转，宽度 480–620px，内部同时展示单据摘要
- 弹窗：仅用于轻量确认与短表单，宽度 440–560px
- 分页：右对齐，含总数、每页条数、页码跳转

## 6. 角色视觉区分
- 管理端：深青侧边栏 + 数据表格式布局，信息密度高
- 公开门户：顶部导航 + 卡片流，浅色背景，无侧边栏
- 登录页：左侧品牌渐变 + 右侧表单卡片，贴合园林主题
