# 组件规范

## 按钮
| 类型 | 高度 | 内边距 | 圆角 | 配色 |
|---|---|---|---|---|
| 主按钮 | 32px | 0 14px | 6px | 背景 `#174A5C`，文字白 |
| 次按钮 | 32px | 0 14px | 6px | 白底，边框 `#DBE7E8`，文字 `#174A5C` |
| 危险按钮 | 32px | 0 14px | 6px | 白底红描边 `#A62B32` |
| 小号 | 28px | 0 10px | 6px | 同上，字号 12px |
| 文本按钮 | - | 0 | - | 链接色 `#316B74`，无边框 |

## 表单
- 标签右对齐，宽度 100–120px；必填项前置红星
- 输入框高 32px，圆角 6px，聚焦边框 `#2A7F86`
- 单列输入宽度 360–520px；搜索下拉 180–240px
- 日期范围使用日期选择器；人员/组织/字典用下拉，不用文本框
- 关闭抽屉前检测未保存内容；复杂表单支持保存草稿

## 表格
- 表头背景 `#EEF5F5`，文字 `#174A5C`，字重 600
- 行高 44px，斑马纹 `#F8FBFB`，悬停高亮
- 表头不写死宽度，按内容自适应并允许横向滚动
- 编号、状态、日期、操作列保持单行（`white-space: nowrap`）
- 图片列 56×42px 圆角 4px，避免行高跳动

## 状态标签
- 浅色底 + 同色描边 + 中文文案，不使用纯色块
- 成功 `#247A58` / 警示 `#8A6A16` / 危险 `#A62B32` / 中性 `#5B6B70` / 主色 `#2A7F86`

## 卡片
- 白底，1px `#DBE7E8` 边框，圆角 8px，内边距 16px
- 标题 15px/600 主色，右侧可放说明小字或操作

## 抽屉与弹窗
- 抽屉宽 480–620px，用于表单编辑与审批流转，内部展示单据摘要
- 弹窗宽 440–560px，用于二次确认与短表单
- 阴影 `0 4px 16px rgba(23,74,92,.12)`，仅这两类容器使用

## 分页
- 右对齐；显示总数、每页条数（10/20/50）、页码与跳转
- 切换筛选条件后回到第 1 页

## 空状态
- 说明产生原因与下一步操作，如「当前筛选条件下无记录，清空筛选或新建养护任务」

## 图表
- 统一调色板：`#174A5C` `#2A7F86` `#316B74` `#7FB3B8` `#A9CDD0` `#247A58` `#C9A227`
- 去掉多余网格线，仅保留浅色水平分割线
- 首页 7 个图表控制在 1440×900 一屏内
